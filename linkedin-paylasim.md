# 🚀 Yeni Proje: Mentora - Mentorluk Yönetim Platformu

Sizlerle Spring Boot ve React kullanarak geliştirdiğim tam kapsamlı mentorluk yönetim platformunu paylaşmaktan mutluluk duyuyorum. Mentora, öğrenci-mentor etkileşimini kolaylaştırmak ve öğrenme süreçlerini dijitalleştirmek için tasarlanmış bir çözüm.

## 💡 Teknik Detaylar:

**Backend:**
- Spring Boot 3.4.5
- JWT tabanlı kimlik doğrulama
- JPA/Hibernate ile veritabanı entegrasyonu
- Rol tabanlı yetkilendirme
- RESTful API mimarisi

**Frontend:**
- React 19 & TypeScript
- Material UI 7 ile modern kullanıcı arayüzü
- React Query ile durum yönetimi
- Responsive tasarım

## ✨ Öne Çıkan Özellikler:
- Öğrenci, mentor ve admin rolleri için ayrı paneller
- Ödev teslim etme ve geri bildirim sistemi
- Güvenli dosya yükleme ve indirme
- Modern, animasyonlu kullanıcı arayüzü
- Rol bazlı kayıt ve giriş seçenekleri

## 🔍 Geliştirme Alanları:
Bu proje öğrenme amaçlı geliştirildiğinden, gerçek dünya uygulamaları için bazı iyileştirme alanları mevcut:

- **Pagination & Sorting:** Büyük veri setleri için pagination ve sorting eklenmeli
- **Test Kapsamı:** Daha kapsamlı birim ve entegrasyon testleri
- **Gerçek Zamanlı Bildirimler:** WebSocket kullanarak gerçek zamanlı iletişim
- **Cache Mekanizması:** Performans iyileştirmesi için Redis gibi bir cache çözümü
- **Ölçeklenebilirlik:** Mikroservis mimarisine geçiş için hazırlık
- **CI/CD Pipeline:** Otomatik build, test ve deployment süreçleri
- **Monitoring ve Logging:** Prometheus veya ELK stack ile izleme sistemi

## 🌟 Öğrenme Yolculuğu:
Bu proje, modern full-stack geliştirme pratiklerini uygulama ve Spring Boot ile React entegrasyonunu derinlemesine öğrenme fırsatı sundu. Token tabanlı kimlik doğrulama, rol bazlı yetkilendirme ve dosya yönetimi konularında değerli deneyimler kazandım.
